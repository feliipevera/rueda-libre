# 🚴 Rueda Libre | Alquiler de bicicletas en Medellín

**Rueda Libre** es un proyecto web desarrollado como parte de mi proceso de formación en Riwi. Consiste en una página web para una empresa ficticia
dedicada al alquiler de bicicletas, recorridos guiados y experiencias sobre dos ruedas en la ciudad de Medellín.

El objetivo es ofrecer una experiencia visual, organizada y fácil de navegar, donde los usuarios puedan conocer los servicios, consultar tarifas y
realizar reservas.

## 🌐 Sitio web

🔗 **[Visitar Rueda Libre](https://feliipevera.github.io/rueda-libre/)**

## ✨ Características principales

El proyecto cuenta con diferentes secciones y funcionalidades:

- **Página de inicio:** presentación de la empresa, sus servicios y modelos de bicicletas disponibles.
- **Tarifas y rutas:** información sobre precios de alquiler, planes y recorridos guiados.
- **Reservas:** formulario para ingresar datos personales, seleccionar bicicletas, fechas y servicios.
- **Rueda Nocturna:** sección especial dedicada a recorridos nocturnos por Medellín.
- **Diseño responsive:** adaptación de la página a diferentes tamaños de pantalla, como computadores, tabletas y celulares.
- **Contenido visual:** imágenes, logotipo y elementos gráficos relacionados con el ciclismo.

## 🛠️ Tecnologías y herramientas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño, estilos y adaptación responsive.
- **Visual Studio Code:** entorno de desarrollo.
- **Git y GitHub:** control de versiones y almacenamiento del proyecto.
- **GitHub Pages:** publicación y alojamiento del sitio web.
- **Live Server:** visualización y pruebas durante el desarrollo.
- **DevTools:** inspección de elementos y pruebas de visualización en diferentes dispositivos.
- **tailwind y broostab:** da a la pagina un diseño unico en todo su contenido

## 📁 Estructura del proyecto

- `index.html`: página principal.
- `css/`: hojas de estilo del proyecto.
- `paginas/`: páginas adicionales, como tarifas y reservas.
- `nocturna/`: sección especial de recorridos nocturnos.
- `img/`: imágenes y recursos gráficos.
- `bitacora.txt`: registro de pruebas, solicitudes y observaciones del desarrollo.

## 🎯 Objetivos del proyecto

- Aplicar los conocimientos adquiridos en HTML y CSS.
- Desarrollar una página web organizada y funcional.
- Implementar diseños adaptables a diferentes dispositivos.
- Comprender la estructura de un proyecto web.
- Practicar el uso de Git y GitHub para gestionar versiones.
- Publicar un sitio web utilizando GitHub Pages.
